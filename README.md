A project build a digital asset exchange system designed to simulate the core infrastructure of modern, high-throughput exchanges like Binance and Bybit.
* Features:
  - Trading pair management
  - Market data service
  - Kline (candlestick) generation
  - Redis caching
  - REST APIs
  - WebSocket support (planned)
  - Kafka event streaming (planned)
  - Order matching engine (planned)
 
* Techstack:
  - Java 21
  - Spring Boot 3
  - PostgreSQL
  - Redis
  - Kafka
  - Gradle Kotlin
  - Docker

* Architecture:
  - common
  - api gateway
  - market data
  - orderbook
  - user porfilo
  - streaming service
